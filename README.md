# **React Phone Catalog**

A modern **online phone catalog** built with **React and TypeScript**.
The application allows users to browse products, view detailed information about devices, add items to favorites, and manage a shopping cart.

The project demonstrates **component-based architecture, state management with Redux, routing, and responsive UI development** commonly used in real-world e-commerce applications.

## **Technologies**

- **React** — building a dynamic component-based user interface
- **TypeScript** — static typing for more reliable and scalable code
- **Redux Toolkit** — state management for Cart and Favorites
- **React Router** — client-side navigation between pages
- **SCSS Modules** — modular and maintainable styling
- **Swiper** — interactive product sliders
- **Vite** — fast development and build tool
- **Git & GitHub Pages** — version control and project deployment

## **Installation**

### **Clone the repository**

```bash
git clone https://github.com/iirk1/React-Phone-Catalog.git
cd project-name
```

### **Install dependencies:**

```bash
npm install
# or
yarn install
```

### **Run the project locally:**

```bash
npm start
# or
yarn start
```

## **Features**

- **Product catalog** with phones, tablets, and accessories
- **Product details page** with image gallery and specifications
- **Favorites system** with global state management
- **Shopping cart** with quantity control
- **Redux state management** for cart and favorites
- **Sorting and filtering** products
- **Pagination** for large product lists
- **Reusable React components** for scalable architecture
- **Fully responsive layout** (mobile / tablet / desktop)
- **Fast navigation** using client-side routing with React Router
